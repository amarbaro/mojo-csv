## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
CSV reader and writer for Mojo byte buffers, with CPython 3.14 quoting rules.
Unquoted fields view the input as Spans; quoted and escaped fields use retained
row scratch. Supports six quoting modes, distinct None and empty string
preservation, invalid UTF-8 passthrough, and ASCII float validation.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- `write_all` is 1.9x faster: 242.5 -> 468.2 MB/s on 714285 records (CPython `csv.writer` on the same rows: 97.1 MB/s).
- `write_all` peaks 36 MB lower on that input (326328 -> 290052 KB): the output is reserved once, with no doubling copies.
- `Dialect(escapechar=...)` now enables escaping. Before, the byte was ignored without `has_escape=True`.
- No reader change: 840k random reader cases, 350k writer cases and 50k `line_num` cases agreed with CPython 3.14.8.

## Changes

### Changed
- `write_all`: one 256-byte stack table flags special bytes, fields without one are copied with a single `extend`, and the output is reserved from the field byte sum.
- `scripts/nightly.sh` requires `MOJO` (no machine path); `scripts/benchmark.sh` alternates Mojo and CPython rounds itself and adds the write mode.
### Fixed
- A nonzero `escapechar` passed without `has_escape=True` was silently ignored, so `a\,b` split into two fields. `has_escape=True` is now only needed for a NUL escape.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- Byte buffers only: no Python file or streaming chunk abstractions. Sniffer, DictReader and DictWriter are excluded.
- Field limit is 131072 bytes, not codepoints. Numeric syntax is ASCII. Error messages are library-specific.
- Row and field views expire at the next `next()` or `reset()`; the compiler does not reject invalid retention.
- `row[index]` has no bounds check in release builds.
- `OwnedField` rows cost about 64 bytes per small field on `read_all` (240732 KB for 50 MB); streaming with `row()` stays at 58288 KB.
- Tried and reverted: quoted fields as input views (+0.9% stream, 0% owned), SIMD width 32 (-7%) and 8 (+3%).
