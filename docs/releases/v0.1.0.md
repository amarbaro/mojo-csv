# mojo-csv v0.1.0

**Released:** 2026-11-07 · **Commit:** the one tagged `v0.1.0` · **Previous:** first release

## What it does

CSV reader and writer for Mojo byte buffers, with CPython 3.14 quoting rules.
Unquoted fields view the input as Spans; quoted and escaped fields use retained
row scratch. Supports six quoting modes, distinct None and empty string
preservation, invalid UTF-8 passthrough, and ASCII float validation.

## Highlights

- Streaming parser runs at 227.50 MB/s versus CPython 85.79 MB/s (2.65x faster) on 49999950 bytes (714285 records) with 58504 KB peak RSS versus 303108 KB.
- Materialized records parse at 102.09 MB/s versus CPython 66.74 MB/s (1.53x faster) with 241324 KB peak RSS versus 562888 KB.
- Zero-copy row and field views: Dialect is 40 bytes, Reader is 168 bytes, CsvField is 24 bytes, OwnedField is 32 bytes.
- 100% parity across 1249 CPython vectors and 5000 randomized differential cases with 0 diffs.
- Dialect validation rejects invalid quoting, delimiter collisions and controls in line terminators.

## Changes

First public release, no earlier version.
Features:
- `struct Dialect`: byte controls (`delimiter`, `quotechar`, `escapechar`, `has_escape`, `doublequote`, `skipinitialspace`, `strict`, `quoting`, `lineterminator`), `validate()`, and presets `excel()`, `excel_tab()`, `unix_dialect()`.
- `struct Reader`: input-bound zero-copy reader `Reader(dialect, Span(input))` with `next()`, `row()`, `reset()`, `read_all()`, and physical line counter `line_num`.
- `struct CsvField`: view struct exposing `data: Span[UInt8]`, `is_null`, and `to_list()`.
- `struct CsvRow`: view struct implementing `len(row)`, `row[index]`, and `to_list()`.
- `struct OwnedField`: owned field container `OwnedField(data, is_null)`.
- `def write_all`: serializes `List[List[OwnedField]]` according to dialect rules.
- Constants: `QUOTE_MINIMAL=0`, `QUOTE_ALL=1`, `QUOTE_NONNUMERIC=2`, `QUOTE_NONE=3`, `QUOTE_STRINGS=4`, `QUOTE_NOTNULL=5`.

## Known limits

- Byte buffers only: no Python file or streaming chunk abstractions.
- Sniffer, DictReader and DictWriter are excluded.
- Field limit is 131072 bytes.
- Row and field views expire upon calling next() or reset(): callers must copy data to retain it across iterations.
- Error messages are library-specific.
